## 2026 Rule Change

Confidence: High. Source: https://ethglobal.com/events/newyork2026

ETHGlobal New York 2026 introduced a visible "Start over. Continue building." rule change. The pre-2026 classic model required an empty starting repo and did not allow existing code. For New York 2026, team size stayed 1-5 and sponsor SDK usage stayed capped at up to three, but the starting point changed to allow any repo a team brings and explicitly welcomes existing code.

Officially described participation paths:

| Track | Starting point | Official framing | Confidence |
|---|---|---|---|
| From Scratch | Empty repo | "Show up. Type `git init`. Ship by Sunday." | High |
| Extend Open Source | Existing maintained open-source repo | Bring a repo already maintained and ship a new feature. | High |
| Ship a Feature | Existing product moving from private to public/open source | Build a new feature on top of an existing product during the event and ship it open source. | High |

Rule implication for research: New York 2026 is not comparable to earlier ETHGlobal hackathons only on "built in weekend from zero." It also measures execution against existing codebases, continuity integrations, and partner-specific continuity bounties.

## Verified Prize-Winner Project Notes

All notes below are limited to projects where the official project detail page exposed a "Winner of" label during access. Confidence is High for award labels and Medium-High for technical interpretation summarized from the project description.

### Kickoff Aivy Studio

- Official page: https://ethglobal.com/showcase/kickoff-aivy-studio-f6o10
- Award verified: Hedera - AI & Agentic Payments on Hedera.
- Notes: Decentralized P2P marketplace on Hedera where AI agents negotiate for buyers and sellers, counter offers, and settle on-chain with HBAR and KUSD. The page also cites World ID identity verification and Ledger hardware wallet support.
- Technical shape: React 18/Vite frontend, React Flow-style workflow builder, and backend services for the agent marketplace flow.
- Lisbon relevance: Strong pattern for Lisbon teams exploring agent-assisted commerce with a non-EVM or app-chain settlement layer.

### ENSFromWei

- Official page: https://ethglobal.com/showcase/ensfromwei-m3nj7
- Award verified: ENS - Integrate ENS, prize pool.
- Notes: Solidity resolver contract implementing ENSIP-10-compatible resolution for `*.fromwei.eth` as `.wei` names.
- Technical shape: ENSIP-10 resolver work with explicit focus on learning and adapting EVM tooling.
- Lisbon relevance: Lightweight identity/naming integrations can still clear sponsor value if they implement protocol-specific behavior rather than cosmetic wallet-name display.

### AgentIndex

- Official page: https://ethglobal.com/showcase/agentindex-psxxo
- Award verified: ENS - Best ENS Integration for AI Agents, 2nd place.
- Notes: Reputation intelligence for ERC-8004 agent registries on Ethereum mainnet, enriched with ENSIP-25 links, claimed ENS names, cross-chain references, and sybil/collision analysis.
- Technical shape: BigQuery backfill over Ethereum logs, JSONL export, SQLite corpus, Python analytics, FastAPI API, and React/Chart.js UI.
- Lisbon relevance: High-value model for Lisbon research around agent identity, registry observability, and on-chain reputation quality.

### Tap Tap Revolution

- Technical shape: Next.js 16/React 19 mobile UI, Coinbase WebSocket price feed, Supabase realtime rooms, Arc USDC escrow, Privy embedded wallets, and ENS subnames for agent mode.
- Lisbon relevance: Consumer crypto games can combine real-time UX, embedded wallets, ENS identity, and low-friction stablecoin settlement.
