## Verified Winners And Finalists

Only entries below have a visible "Winner of" marker on the official ETHGlobal project detail page checked on 2026-06-22. I did not infer award status from showcase ordering.

### Veryclear

- Official project URL: https://ethglobal.com/showcase/veryclear-vu8i7
- Verified award: Ledger - Clear Signing, Integrations & Apps, 1st place.
- What it builds: a DSL for human-readable Ethereum transaction descriptions. It takes transaction calldata and produces natural-language templates with holes that can be filled on a Ledger-style edge device.
- Technical notes: the page says the DSL is implemented in Lean and produces ZK circuits; proofs are generated on the frontend and verified on the edge device.
- Theme fit: DevTools, wallet safety, clear signing, Zero Knowledge Proofs, Privacy & Security.
- Lisbon relevance: Medium. Useful to Lisbon/Portugal teams building safer wallet, fintech, or DeFi signing flows for EU users because it targets transaction comprehension and device-side verification.
- Confidence: High for award and technical summary; Medium for Lisbon relevance.

### EVM PORST

- Official project URL: https://ethglobal.com/showcase/evm-porst-kkcfo
- Verified award: ETHGlobal - ETHGlobal Cannes 2026 Finalist.
- What it builds: an EVM implementation of the PORST signing scheme from Gravity-SPHINCS as an alternative building block to HORS/FORS-style post-quantum signatures.
- Technical notes: the page says witness sizes are smaller than HORS(T) and FORS, reducing verifier work and gas. It is implemented in Solidity, mostly Yul assembly, with Foundry, no dependencies, and a focus on minimizing signature witness words.
- Theme fit: Privacy & Security, DevTools, post-quantum wallet/account infrastructure.
- Lisbon relevance: Medium. Relevant to Portuguese and EU wallet/security teams tracking post-quantum migration risk and gas-sensitive verification on EVM chains.
- Confidence: High for finalist status and project facts; Medium for Lisbon relevance.

### OpenCompliance

- Official project URL: https://ethglobal.com/showcase/opencompliance-b89x9
- Verified award: Chainlink - Best usage of Chainlink privacy standard.
- What it builds: a shared, verifiable compliance orchestration layer for institutional DeFi using Chainlink CRE and Chainlink ACE on Arc.
- Technical notes: KYC, AML, sanctions, and per-trade checks run inside TEEs on a decentralized oracle network, producing onchain attestations, trade checks, and audit trails. The project page cites four TypeScript-to-WASM CRE workflows, Chainlink's 21-node DON, Confidential HTTP, Vault DON, seven Solidity contracts on Arc Testnet, and a demo swap protocol with multiple integration patterns.
- Theme fit: TEEs, Privacy & Security, Interoperability, DeFi, institutional compliance.
- Lisbon relevance: Medium. Relevant to Lisbon fintech, regtech, and DeFi teams that need privacy-preserving compliance patterns for European institutional users.
- Confidence: High for award and technical summary; Medium for Lisbon relevance.

### maki

- Official project URL: https://ethglobal.com/showcase/maki-564eg
- Verified award: ETHGlobal - ETHGlobal Cannes 2026 Finalist.
- What it builds: a hardware-signed onchain DeFi agent where the model interprets natural-language intent but cannot directly move funds.
- Technical notes: the write path is interpret -> resolve -> build -> simulate -> policy check -> deterministic summary -> human approval -> sign -> submit. The page describes TypeScript, viem, ERC-4337 tooling, Pi runtime, a local signer boundary, Apple Secure Enclave plus LocalAuthentication, a Ledger path, World AgentKit proof, and Uniswap Trading API routing.
- Theme fit: AI x Crypto, DeFi, Crypto Consumer, wallet security, DevTools.
- Lisbon relevance: Medium. Relevant to Lisbon builders exploring AI-agent UX without weakening signing custody, especially for consumer DeFi and wallet prototypes.
- Confidence: High for finalist status and technical summary; Medium for Lisbon relevance.

### SENTINEL

- Official project URL: https://ethglobal.com/showcase/sentinel-91nv5
- Verified award: Flare - Next generation of apps with TEE Extensions and Smart Accounts, 3rd place.
- What it builds: decentralized AML scoring where independent TEE nodes score wallet risk, Chainlink CRE aggregates results, and users can produce verifiable Proof of Innocence attestations onchain.
- Technical notes: the project page cites an XGBoost model trained on 200k+ labeled Bitcoin transactions, five risk dimensions, Flare Confidential Space, flare-ai-kit attestations, Chainlink ConfidentialHTTPClient, VaultDON-managed secrets, AES-GCM encrypted outputs, eight Solidity contracts, Flare Coston2, FTSO, FDC, Smart Accounts for XRPL users, Arc nanopayments, and a Next.js frontend.
- Theme fit: TEEs, Privacy & Security, Interoperability, compliance, AI x Crypto.
- Lisbon relevance: Medium. Relevant to Lisbon and Portuguese DeFi or payment teams evaluating AML, proof-of-innocence, and privacy-preserving risk infrastructure for European markets.
- Confidence: High for award and technical summary; Medium for Lisbon relevance.
