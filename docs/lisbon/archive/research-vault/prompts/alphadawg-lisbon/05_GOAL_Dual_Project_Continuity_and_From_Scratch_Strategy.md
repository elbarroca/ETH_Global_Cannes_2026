## Phase 5 — Score, challenge, and select Project B

Score all 20 ideas out of 100:

- user pain clarity: 12
- sponsor inevitability: 18
- AI-agent necessity: 10
- inspectable proof artifact: 12
- replayable happy/failure demo: 12
- 36-hour feasibility: 12
- novelty versus prior winners: 10
- practical adoption wedge: 8
- coherent maximum-three-partner overlap: 6

Apply penalties after the base score:

- minus 20 if a mandatory qualification path cannot be shown end to end;
- minus 15 if sponsor use is decorative;
- minus 15 if the idea depends on unpublished track details;
- minus 10 if the main proof is self-reported or mock-shaped;
- minus 10 if the live demo depends on uncontrolled liquidity, hardware, partner uptime, or mainnet spend without a deterministic fallback;
- reject if the concept is substantially the same as a prior project without a defensible new mechanism or user wedge.

Then run an adversarial review:

- What would a skeptical judge call fake, old, generic, or unnecessary?
- What breaks if each sponsor is removed?
- Can a malicious or malformed agent create value movement?
- What happens on timeout, duplicate request, stale quote, failed proof, partial payment, or transaction ambiguity?
- Can the demo be reset and replayed twice?
- Can Person B actually finish it alone within the event window?

Selection gates:

1. Rank all 20.
2. Produce a top-five shortlist.
3. Deep-diligence the top three against official docs, starter repos, current SDKs/APIs, testnet access, and demo requirements.
4. Select one primary `BUILD` concept only if it scores at least 80 after penalties and has no unresolved hard qualification dependency.
5. Select one backup that does not share the primary's largest external dependency.
6. If none passes, return `STOP_IDEATION_NOT_VALIDATED` and state the exact research/access needed; do not force a winner.

- sponsor-specific implementation map;
- test and evidence matrix;
- 36-hour backlog with hour gates and cut order;

- setup/access checklist;
- explicit `BUILD / NARROW / STOP` contract.
