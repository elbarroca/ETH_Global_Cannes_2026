## Purpose / Ideation

| field | value |
|---|---|
| one-line product | Were building the Moodys of Solana DeFi. YieldCompass is a search engine for yield opportunities: it shows what you actually earn (realized APY), and how risky it is (transparent risk ratings) to earn it. If DeFi seriously aims at becoming the alternative to TradFi, it needs to provide better transparency standard so that everyday users can allocate capital more intelligently. That's the gap we close. |
| user pain | Yield users chase headline APY without risk-adjusted context. |
| solution loop | Search engine shows realized APY and transparent protocol risk scores. |
| why it likely fit Colosseum | Likely scored because it turns DeFi yield into a decision metric. |
| hackathon idea lesson | Directly reinforces Lisbon LVR/risk scorecard pattern. |
| reject if | Yield dashboard with no transparent scoring or action. |
