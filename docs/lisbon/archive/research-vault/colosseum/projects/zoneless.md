## Purpose / Ideation

| field | value |
|---|---|
| one-line product | Zoneless is an open-source alternative to Stripe Connect using USDC on Solana. It lets marketplaces pay their sellers globally at near-zero cost: ~$0.002 per payout vs $2+ on Stripe. It has an identical API to Stripe Connect, so developers can migrate in minutes with no code changes. Apache 2.0 licensed and fully self-hostable. |
| user pain | Solana developers need ecosystem-benefiting public goods. |
