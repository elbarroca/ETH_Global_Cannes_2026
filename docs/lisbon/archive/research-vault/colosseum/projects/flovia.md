## Purpose / Ideation

| field | value |
|---|---|
| one-line product | Flovia is the growth analytics & intelligence for machine-paid APIs. We help API providers on x402 / MPP understand where agent demand comes from, which agent user(wallets), acquisition channels drive retained usage, and decide what to do next across repricing, partnerships, GTM, and API packaging. Flovia turns fragmented agent payment and usage data into predictable API growth. |
| user pain | Machine-paid API providers lack clear usage and growth intelligence. |
| solution loop | Analytics platform converts payment and usage data into predictable API growth signals. |
| why it likely fit Colosseum | Likely scored because machine payments become a measurable business dashboard. |
| hackathon idea lesson | Directly strengthens Lisbon x402 service desk and paid API observability. |
| reject if | Dashboard that does not change pricing, routing, or retention decisions. |
