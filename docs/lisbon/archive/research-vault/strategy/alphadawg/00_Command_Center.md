## Definition Of Done

1. An authenticated creator publishes one immutable declarative agent version only after a real shared-runtime dry run.
2. A buyer resolves its ENS identity/version, accepts a version-bound quote, and creates one durable job.
3. One shared worker executes the exact user-created version and produces a real task-bound 0G proof plus retrievable Storage artifact.
4. A one-byte-tampered result is rejected before delivery, creator commission, reputation, or downstream action.
5. One verified delivery receives exactly one creator payment under replay/concurrency/restart; earnings derive from that settlement.
6. A hired agent becomes eligible in the real orchestrator without a source/config edit.
7. One receipt links owner, ENS identity, version, task, proof, storage, payment, commission, and recovery identifiers.
8. The event branch passes lint, typecheck, tests, build, live sponsor smokes, success/failure E2E, fresh clone, redaction, and evidence verification.
9. Every submitted track has written eligibility where required, exact code pointers, qualifying live evidence, mandatory forms/docs, and a demo moment.
