# Lisbon 2026 Two Person H0 Runbook

> [!danger] Do not execute early
> Run only after the official ETHGlobal dashboard/schedule states hacking is open. Research pages and this runbook do not authorize H0.

## Shared H0 Gate

Both people independently record:

- Official H0 timestamp, submission deadline, current rules, selected partner pages, categories, maximum-three-partner rule, AI disclosure, demo/video/booth requirements.
- Identity/team/stake status and decision authority.
- Approved testnet-only spend cap; no mainnet.
- Account manifest using only `SET/NOT_SET`, never secret values.
- Separate repo, wallet, database, cloud, domain, evidence, demo, and submission boundaries from [[01_Provenance_and_Team_Separation]].

If H0, ownership, team status, or spend authority is unclear, no product code begins.

## Verification Commands

Exact scripts are created after H0; equivalent required outcomes are:

```bash
<package-manager> install --frozen-lockfile
<package-manager> lint
<package-manager> typecheck
<package-manager> test
<package-manager> build
<package-manager> secret-scan
<package-manager> smoke:sponsor
<package-manager> test:e2e -- success
<package-manager> test:e2e -- tampered-or-refused
<package-manager> evidence:verify
```

Live/spending tests must require explicit opt-in, named Testnet, amount cap, and redacted output. A fixture may test offline logic but cannot satisfy sponsor evidence.

## Evidence Capture

For each project record independently:

- commit SHA and changed-file boundary;
- exact package/SDK versions;
- redacted inputs and canonical hashes;
- public sponsor/network identifiers and timestamps;
- success, tampered/refused, timeout, replay/restart, and unavailable-sponsor outcomes;
- negative assertion proving no downstream signing/value movement;
- command outputs/exit codes, fresh-clone result, screenshots, video timestamps;
- selected track, mandatory form/booth/artifact completion.
