4. [Project B beginner operator card](../research-vault/strategy/dual-project/PROJECT_B_LISBON_MASTER.md#0-beginner-operator-card) for the from-scratch lane.
5. Use the [AlphaDawg operator appendices](../research-vault/strategy/alphadawg/ALPHADAWG_LISBON_MASTER.md#19-operator-appendices--ownership-data-failure-and-proof) or [Project B operations annex](../research-vault/strategy/dual-project/PROJECT_B_LISBON_MASTER.md#14-beginner-executable-operations-annex) for owners, access, exact gates, error decoding, ledgers, H0 print cards, and rehearsals.

7. Use the matching H0 goal as the autonomous execution contract, not as permission to start early.

`H0` means the official hacking start. Before H0: research, rule/access checks, and planning only. Never pre-create Project B code/design/prompts/assets, change AlphaDawg product code, mix the projects, expose secrets, spend, deploy, sign/broadcast, or claim qualification.
